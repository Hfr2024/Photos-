# ستايل ستوديو

تطبيق ويب (PWA) لتحرير الصور بالذكاء الصناعي، يعمل مجاناً على GitHub Pages.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `style-studio`).
2. ارفع الملفات الخمسة إلى جذر المستودع: `index.html` و`manifest.json` و`sw.js` و`icon.svg` و`README.md`.
3. من **Settings ← Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
4. بعد دقيقة يظهر الرابط: `https://اسم-المستخدم.github.io/style-studio/`
5. افتح الرابط من الموبايل واختر **إضافة إلى الشاشة الرئيسية** ليعمل كتطبيق.

## كيف تعمل كل ميزة

| الميزة | أين تُعالَج | التكلفة |
|---|---|---|
| إزالة الخلفية وفصل الشخص | داخل المتصفح (`@imgly/background-removal`) | مجاني، ويحمّل نموذجاً (~40MB) أول مرة |
| تحسين الصور (تكبير، حدّة، ألوان، إضاءة) | داخل المتصفح (Canvas) | مجاني |
| تغيير الملابس | Hugging Face Space (`yisol/IDM-VTON`) | مجاني بحصة محدودة |
| توليد الخلفيات والعناصر | خدمة Pollinations (قابلة للتغيير من الإعدادات) | مجاني |

## ملاحظات مهمة

- **حصة Hugging Face:** المساحات المجانية تستخدم ZeroGPU وحصتها اليومية للزوار بدون حساب صغيرة. أنشئ مفتاحاً مجانياً من huggingface.co/settings/tokens وضعه في **إعدادات الخدمات** داخل التطبيق لتزيد الحصة.
- **تغيّر الخدمات:** المساحات المجانية قد تتغير أو تتوقف. إن لم يعمل التركيب، ابحث في Hugging Face عن Space بديل لـ Virtual Try-On وضع اسمه في الإعدادات (يجب أن يدعم نفس واجهة `/tryon`).
- **توليد الصور:** إن توقفت خدمة التوليد، غيّر الرابط في الإعدادات إلى أي خدمة تقبل `{prompt}` و`{w}` و`{h}` و`{seed}` في الرابط.
- **الخصوصية:** فصل الخلفية والتحسين يتمّان على جهازك. التركيب والتوليد يرسلان الصورة أو الوصف إلى الخدمة الخارجية.
- **الحفاظ على الوجه:** نموذج التركيب يعدّل الملابس فقط. وإضافة العناصر وتغيير الخلفية لا تلمس وجه الشخص لأنه مفصول كطبقة مستقلة.

## ترتيب الاستخدام المقترح

الملابس ← الخلفية ← العناصر ← التحسين (التحسين يدمج كل شيء في صورة واحدة).
